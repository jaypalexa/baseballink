162 Game Average
This is an attempt to condense each pitcher's career into a single season's worth of stats. 
With batters this is easy. Just take their career games played and divide by 162 and then divide their career totals by that factor. 
For pitchers, this is more difficult. What I have done is treat a pitcher season as having Games Pitched + Games Started = 68 as a single-season. 
So I normalize everything, so a pitcher has Games + Games Started = 68. So an average season is 34 starts or 68 relief appearances. 


pitchingCareerIP = (SUM(IIF(ISNULL(Pitching.IPouts), 0, Pitching.IPouts)) / 3) 
pitchingCareerG = (SUM(IIF(ISNULL(Pitching.G), 0, Pitching.G))) 
pitchingCareerGS = (SUM(IIF(ISNULL(Pitching.GS), 0, Pitching.GS))) 
pitchingAvgIPPerSeason = (pitchingCareerIP / ((pitchingCareerG + pitchingCareerGS) / 68)) 
pitchingTotalSeasons = (pitchingCareerIP / pitchingAvgIPPerSeason) 
avgWAR = (CareerWAR / pitchingTotalSeasons)
